# EXPO. Paris

Prototype d'application mobile pour explorer les expositions à Paris.

## Installation
Déposer tous les fichiers de ce dossier à la racine du dépôt GitHub (pas le ZIP).
Netlify : branche `main`, base directory vide, build command vide, publish directory vide.

## Important
Cette version est une **maquette fonctionnelle** : les expositions et dates du catalogue
ne sont pas vérifiées en temps réel. Les images peuvent être illustratives et les liens
mènent souvent au site général des institutions. Elle ne dispose pas encore d'une
collecte automatique des expositions. Ne pas la présenter comme un agenda exhaustif
ou fiable sans vérification éditoriale.
